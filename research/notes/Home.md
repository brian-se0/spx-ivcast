# Research notes

Notes on the literature behind [[paper]]. Each source has one note in `literature/`, named by citation key, with the in-text citation form as an alias, so a search or an unlinked-mentions lookup for "Cont and da Fonseca (2002)" finds both the note and the places the paper cites it.

- The properties at the top of each note (asset class, sample, forecast object, horizon, methods, benchmarks, evaluation design, loss metrics, headline finding) drive the tables below.
- `status: cited` marks a source in the paper's reference list. `status: uncited` marks another PDF held in `lit_review/`.
- `pdf` links point into `lit_review/`, which is kept out of version control, so they resolve only where the library is present. A cited source with `pdf_version: none` has no PDF in the library and its content fields are unread.
- Each note ends with `Use in this study`, linking to the section of the paper that cites it.
